# space-invaders
This is a space invaders game. There are 3 classes GameModel.java, GameView.java, and GameController.java. GameModel.java handles the game logic, GameView.java handles the graphics, and GameController.java handles the controls. The aliens are either a square, a circle, or a triangle. There are also 3 blue aliens per wave. Destroying a blue alien will increase bullet count. Losing a life decreases bullet count unless you are at 1 bullet. After defeating all the aliens, a new wave will spawn where the aliens move faster and shoot faster. A high score is saved between games and displayed in the top left of the screen.
